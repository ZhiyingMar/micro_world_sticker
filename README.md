# 🧲 冰箱贴小世界

**在线试玩：https://zhiyingmar.github.io/micro_world_sticker/**

一个网页上的探索收集小游戏：冰箱上的每一块冰箱贴，都是一个可以放大、旋转的立方体小世界。在世界里找到 3 样隐藏的东西，它们会合成下一块冰箱贴，带你去风格完全不同的新世界。

## 世界

| 冰箱贴 | 风格 | 简介 |
|---|---|---|
| 🏠 我的小屋 | 动森风 | 温暖的小房间，起点 |
| 🍄 童话森林 | 童话风（卡通着色） | 林子里散着的蘑菇屋、山顶高塔、踩着踏脚石过池塘、翻蘑菇 |
| 👾 像素小镇 | 像素风（低分辨率渲染） | 缓坡上的方块小镇：风车、喷泉广场、菜园和稻草人、小瀑布，一格一格的台阶走上去叮咚响，小鸡会扑腾着跑开 |
| 🌃 霓虹夜都 | 都市风 · 夜晚 | 霓虹招牌、亮灯的高楼、会礼让斑马线的车流 |
| ☔ 雨天伦敦 | 英伦风 · 雨天 | 双层巴士、红电话亭、大本钟，下雨、打雷 |
| 🏖️ 海边假日 | 夏日风 · 晴天 | 透明的海水和小鱼、椰子树、沙堡、救生塔、栈桥，最后一个世界 |
| 🖼️ 全家福 | — | 集齐所有世界后获得的纪念冰箱贴，点开是结局 |

每个世界里都住着几个小人，会自己坐下喝茶、看书、等公交……

## 玩法

- **上帝视角**：拖动旋转、滚轮/双指缩放，点击任何地方放大看细节；点小人可以聊天，台词里藏着提示。
- **进入生活**：作为一个小人进入世界，WASD / 方向键 / 虚拟摇杆 / 点击地面走动，靠近东西自动捡起，E 键或互动按钮聊天。
- **冰箱**：收集到的冰箱贴都贴在冰箱上，点一块就能去对应的世界。
- 支持电脑和平板/手机触控，进度自动保存在浏览器里。

## 运行

需要 Node.js 18+（线上构建用的是 Node 26）。

```bash
npm install
npm run dev
```

打包：`npm run build`，产物在 `dist/`，是纯静态文件，可以放到任意静态托管上。

### 录宣传片

网址后面加 `?trailer`（比如 `http://localhost:5173/?trailer`），点「● 开始录制」：游戏会按 `src/trailer/shots.js` 里的分镜自动演一遍小屋和霓虹夜都（约一分钟），连游戏音效一起录成 1080p 视频。开发服务器上录完直接存到 `recordings/`，不然点面板上的链接下载。

- 是按真实时间录的：录的时候窗口要一直在前台、别被挡住，不然浏览器会降速，画面会掉帧
- 宣传片用一份只在内存里的进度，不会动你自己的存档

推送到 `main` 分支后，GitHub Actions（`.github/workflows/deploy.yml`）会自动打包并发布到 GitHub Pages。

## 代码结构

```
src/
  main.js        渲染、相机、点击/触控、收集与切换世界
  world.js       一个世界的容器：碰撞、物品、居民、兴趣点
  villager.js    小人：外形、走路动画、日常行为、玩家操控
  kit.js         造型工具（按风格切换材质）、贴图工具
  fx.js          闪光粒子、表情气泡、光晕、霓虹文字
  audio.js       WebAudio 合成的音效和环境声
  ui.js          界面：收集栏、对话框、冰箱、合成动画
  terrain.js     有高低的地面：用文字地图描述
  scenes/        每个世界一个文件；大的世界一个文件夹（比如 scenes/city/）
```

### 加一个新世界

1. 在 `src/scenes/` 新建一个文件，导出包含 `id`、`name`、`style`、`items`（3 样物品及其模型）、`next`（下一个世界）和 `build(w)`（搭场景、放物品、放居民）的对象，可以参考 `pixel.js`（一个文件的世界）；大的世界照 `forest/`、`city/` 拆成文件夹。
2. 在 `src/scenes/index.js` 里注册，并加入 `ORDER`。
3. 把上一个世界的 `next` 指向它。

技术栈：[three.js](https://threejs.org/) + [Vite](https://vitejs.dev/)，所有模型都是用代码拼出来的，没有外部美术资源。
