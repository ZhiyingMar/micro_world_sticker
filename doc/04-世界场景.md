# 04 · 世界场景

## 1. 一个世界的定义长什么样

`src/scenes/` 里每个世界导出一个普通对象（`def`）。以童话森林（`forest/index.js`）为例（值有简化，常量都在 `forest/layout.js`）：

```js
export default {
  id: 'forest',                 // 唯一 id，存档里用它
  name: '童话森林',
  emoji: '🍄',
  style: 'toon',                // 材质风格：cozy / toon / pixel（见 kit.js）
  styleLabel: '童话风',          // 标题卡上的小字
  magnetStyle: 'toon',          // 冰箱贴的 CSS 样式（style.css 里 .magnet--toon）
  bg: 'linear-gradient(...)',   // 方块外面的背景（CSS）
  lights: {
    hemi: ['#e8f7ff', '#b5e39a', 1.9],      // 半球光：天空色、地面色、强度
    sun: ['#fffbe8', 2.6, [6, 12, 5]],      // 方向光：颜色、强度、位置
  },
  camera: { pos: [11.5, 11, 14.5], target: [0, 0.6, 0], fitH: 4, min: 2.5 },
  terrain: { map: MAP, level: 0.5 },  // 有高低的地面：一张文字地图
  spawn: [-1.4, 5.2],           // 玩家出生在哪 [x, z]
  greet: { name: '波波', text: '…' },   // 第一次进来谁主动打招呼
  next: 'pixel',                // 集齐 3 样后合成哪个世界的冰箱贴
  materials: [{ id: 'mushroom', name: '小蘑菇', icon: '🍄', make }],  // 能翻出来的材料
  scatter: [{ material: 'mushroom', count: 5, from: ['bush', 'stump', 'leaves'] }],
  items: [                      // 要找的 3 样东西
    { id: 'coin', name: '像素金币', icon: '🪙', hint: '池塘里，踏脚石拐弯那儿的荷叶上', make(kit) { return …THREE.Group } },
    …
  ],
  build(w) { … },               // 搭场景：摆模型、登记碰撞、放物品、放小人
};
```

### 全部可用字段

| 字段 | 必须 | 说明 |
|---|:-:|---|
| `id` `name` `emoji` `style` `styleLabel` `magnetStyle` `bg` `lights` `spawn` `next` `items` `build` | ✓ | 见上 |
| `camera` | ✓ | `pos`/`target` 定全貌的方向；`fitH` 全貌取景时后排要算多高；`min` 最近能拉多近；可选 `minPolar` `maxPolar` `minAz` `maxAz`（角度限制）、`startAz` `startPolar`（一进来的角度）、`fitSize`（全貌只框住一部分地面） |
| `greet` | | 对象，或 `(world) => 对象`（夜都按停电/修好说不同的话，`key` 不同各说一次） |
| `ambient` | | 环境声：`'rain'` `'city'` `'sea'` `'forest'`（溪水声 + 隔一会儿的鸟叫） |
| `terrain` | | `{ map, level }` 有高低的地面；有了它，世界大小和边界都跟着地图走 |
| `size` / `bounds` | | 没有地形时自己定大小和可走范围（默认 10×10，±4.55） |
| `repairs` + `brokenGoal` | | 破败世界：要放回的东西 `[{ id, from, hint, msg }]`，`from` 是哪个世界带来的 |
| `materials` + `scatter` | | 这个世界能捡的材料和每次随机藏多少、藏在哪类地方 |
| `test` | | 测试场景，不写进存档的"当前世界" |
| `ending` / `comingSoon` | | 全家福结局 / 还没做好的世界（冰箱上点了提示"施工中"） |

### 注册

`src/scenes/index.js` 把所有世界放进 `SCENES`，并定好顺序：

```js
export const ORDER = ['home', 'forest', 'pixel', 'city', 'london', 'beach', 'finale'];
export const HOME = 'home';                                   // 家，不算冰箱贴
export const MAGNETS = ORDER.filter((id) => id !== HOME);      // 冰箱上的 6 块
export const WORLDS = ORDER.filter((id) => !SCENES[id].ending); // 真正能进去的
```

`finale`（全家福）不是一个世界，只是一个 `ending: true` 的冰箱贴定义，点开显示结局。

## 2. 世界链和物品的设计巧思

每个世界藏的 3 样东西，**都是下一个世界的"种子"**：

| 世界 | 风格 | 藏的 3 样 | → 合成 |
|---|---|---|---|
| 🏠 我的小屋 | cozy 动森风 | 🍄 红蘑菇、📖 童话书、⭐ 魔法星星 | 🍄 童话森林 |
| 🍄 童话森林 | toon 卡通着色 | 🪙 像素金币、❤️ 像素爱心、🎮 游戏卡带 | 👾 像素小镇 |
| 👾 像素小镇 | pixel 低分辨率 | 🌙 小月亮、🚕 小出租车、🎷 萨克斯 | 🌃 霓虹夜都 |
| 🌃 霓虹夜都 | cozy · 夜晚 | 🌂 红雨伞、🎩 绅士礼帽、🫖 红茶壶 | ☔ 雨天伦敦 |
| ☔ 雨天伦敦 | cozy · 雨天 | 🕶 太阳镜、🐚 扇贝壳、🏐 沙滩球 | 🏖️ 海边假日 |
| 🏖️ 海边假日 | cozy · 晴天 | ⭐ 海星、🪣 小水桶、📷 旧相机 | 🖼️ 全家福（结局） |

霓虹夜都更进一步：像素小镇带来的月亮、出租车、萨克斯，在夜都里是**要放回原处的零件**（修复点），而不是背包里的普通物品。

## 3. 各个世界

### 🏠 我的小屋 `home/`

起点，也是唯一能自己改的地方。照森林的画面样板改过：手作感的地板墙面、会动的小东西、碰一下有反应、外面一圈花园。`index.js` 的 `build`：

```js
build(world) {
  const room = buildRoom(world);          // 地板、两面墙（后墙开了窗洞）、窗户、墙上的画和会跳的钟
  placeEaves(world);                      // 墙顶的房檐
  placeGarden(world);                     // 屋外一圈花园
  const furnitureKit = createFurnitureKit(world);           // 家具共用的木纹、布料材质
  const furniture = buildFurniture(world, furnitureKit);   // 家具、碰撞、兴趣点
  placeWorkbench(world, room, furnitureKit);
  placeCat(world);                        // 毛线篮旁边睡觉的小猫
  // …藏的 3 样东西、居民…
  const puffs = createPuffs(world);       // 热气、扬灰用的一小团雾
  bringToLife(world, { curtains, spout, radio, puffs }); // 窗帘晃、茶壶冒热气、收音机飘音符
  createTouch(world);                                    // 踢毛线球、脚步声
}
```

- 只有后墙和左墙两面墙，镜头被限制在右前方斜着看（左右约 ±25°），转不到正对墙。
- **光和声音**：午后的暖光从左前方照进来（左墙在地上投一道影子），天光偏冷；环境声 `home`（屋里很轻的底噪 + 窗外鸟叫）。墙根、墙角铺一圈淡阴影。试过从窗户斜照进来一道光柱和地上的亮斑，可光是从左前方照来的，和窗光方向相反，拿掉了。
- **地板**：`decor.js` 里画的是窄木板（一排约 0.4 宽），长短不一、有木纹和木节；只有顶面铺装修贴图，侧面是木头收边。
- **家具**：`furniture-models.js` 只造不摆（正面朝 +z），`furniture.js` 按 `layout.js` 的 `FURNITURE`、`STOOLS` 摆、登记碰撞和兴趣点。木头部分都用 `materials.js` 的木纹（`projectUVs` 按位置铺，木纹一样密、顺着长边走），和地板像一套；布料有拼布、毛线、编织、藤编的花纹。圆角方块按大小分段（`roundedBox`），小零件圆角只分一段，省三角形。
- **凳子**：有碰撞，挡人。坐凳子的兴趣点定在凳子旁边，带 `seat`（凳子中心）：小人走到旁边一步挪上去坐，站起来挪回原地（`villager.sitDown`），不会卡进碰撞里。
- **窗户**：后墙用 `ExtrudeGeometry` 真的开了洞（贴图坐标按位置算，换壁纸图案不挤歪），透过窗洞看得到屋后的树和两棵向日葵。
- **冰箱**：模型上每个网格都挂 `userData.action = 'fridge'`，点它或走近按 E 打开冰箱面板；`world.fridge` 存着它，别的地方用它的位置。
- **工作台**：左墙边，`w.interact('workbench', …)` → `env.openWorkbench(pick)` → 面板上选款式 → `decor.chooseDecor()` 扣材料、存档 → `room.applyDecor()` 换墙纸地板和外面的背景。
- **碰一下有反应**（`touch.js`、`cat.js`，都只是好玩，不进存档）：地上的毛线球踢一下会滚走、撞墙会弹；很轻的脚步声跟着步子（`phase`），木地板上"嗒"、地毯上闷闷的；小猫平时呼吸、甩尾巴、抖耳朵、冒 💤，人走近会抬头看过来"喵"一声，人走开一会儿又睡。撞到家具不晃也不响（试玩嫌吵）。
- **花园**（`garden*.js`）：圆角的草地方块，侧面露出土层和小石头；尖头篱笆、推开的院门、红信箱，石板小路弯到屋子右边的木台阶；屋后屋左几种树（`src/plants.js`）从房檐上冒出来、风吹树冠；花一簇簇长在篱笆脚、路边、地基边和树下，满地草丛，几只蝴蝶（`src/butterflies.js`，人走到屋边会惊飞）。只是看的，`bounds` 还是屋里那块地板，人走不出去（所以花园里摆东西不能用 `world.blocked`，`garden.js` 自己记哪儿被占了）。`size` 设成花园大小，`camera.fitSize` 只框住屋子。
- 居民：小橘（第一次打招呼）、阿绵。兴趣点：床边打盹 💤、看书 📖、窗前晒太阳 ☀、喝茶 ☕（`w.poi(...)`，小人闲逛时会随机走过去）。
- 三角形大约 18 万（花草、草丛都用 `InstancedMesh`，圆角方块按大小分段）。

### 🍄 童话森林 `forest/`

14×14，有地形，照夜都拆成一个文件夹（没有剧情、没有小游戏）。也是**画面样板**：地面用 `terrain-soft.js` 画成圆润的网格，植物有层次和疏密，风吹、水流、蝴蝶、鸟叫让它活起来。`index.js` 的 `build`：

```js
build(world) {
  const ground = buildGround(world);   // 圆润的地面、草地深浅、土路
  const village = buildVillage(world); // 三座蘑菇屋，散在林子里
  buildPond(world, ground);            // 水线上的石头、荷叶、金币、拦住小溪口的大石头
  buildHill(world);                    // 右后角小山：高塔、塔背后的花丛和卡带
  buildForage(world);                  // 灌木丛、树桩、落叶堆：能翻蘑菇的地方
  const woods = buildWoods(world);     // 显眼的几棵树、四周树墙、空心木头（爱心）、栅栏
  buildScenery(world);                 // 一簇簇的花、满地草丛、侧面小石头、萤火虫
  createPeople(world);                 // 波波、莉莉、蘑菇仔
  const splashes = createSplashes(world, ground.waterSurface);   // 水面上的波纹、水珠
  bringToLife(world, { crowns: woods.crowns, waterSurface: ground.waterSurface, splashes });  // 风、蝴蝶、鱼
  createTouch(world, { houses: village.houses, splashes });      // 碰一下会有反应的东西
}
```

后面几步要避开前面摆好的东西（树墙不挡能翻的地方和兴趣点，花草不长进树干和路上），所以顺序不能乱。

```
z -7  000000 1111 2222   左后：林子里的红蘑菇屋   右后：两层小山，山顶是高塔
      000000 111> 2222   山腰往右一级台阶上山顶，正好从塔背后上去
      000000 11111111    山腰绕到山前面的一条窄道
      0000000~~0000^     右边草地的台阶上山腰
      000000~ooo0000     o 踏脚石，弯弯曲曲穿过池塘
      1110000~~~0000     左边一层的小土坡（台阶 <），上面黄蘑菇屋；右边草地上蓝蘑菇屋
      ...       =        小溪往前流，上面一座桥，流到边上被大石头拦住
```

- **小山和池塘把森林分成左右两半**，只有池塘里的踏脚石和小溪上的桥能过去，能绕一圈走。
- **三座蘑菇屋散在林子里**，不挤在一处：红的在左后林子里，黄的在小土坡上，蓝的在右边草地上，各有一条土路通到门口。每座屋子周围留一块空地（`HOUSE_CLEARING`），树墙不往里种；屋子之间补了几片小树林。
- **小溪口**：水流到方块边上的地方（按地图找，不写死位置），两岸各压一块大石头，水里横一排小石头拦住，水不会直接从边上流出去。
- 上山顶要绕着山走：右边台阶上山腰 → 沿山腰往左 → 一级台阶上山顶，刚好到塔背后的花丛，卡带就在那里（默认镜头被塔挡住）。
- 金币在踏脚石拐弯处的荷叶上，站在石头上点得到。
- 空心木头挂了 `userData.peek`，点它镜头会转到开口往里看——爱心就藏在里面。
- 高塔和蘑菇屋登记了 `fadeable`，人走到后面时变半透明。
- 翻蘑菇：灌木丛（露出一点）、树桩（长在树桩脚下，看得见）、落叶堆（翻开才知道），`layout.js` 的 `MUSHROOM_HIDING` 定每次随机长 5 个。
- **植物**（`src/plants.js`，小屋花园也用）：圆冠树、松树、杨树三种，树冠深浅错开；树冠单独一个组，风吹只摇树冠。后边和左边（离镜头远）按规则种两排树墙，前边和右边只种矮灌木，不挡视线。
- **花是设计出来的**：屋前两边各一小片（颜色跟着屋顶）、路边隔一段一簇、显眼的树底下一簇、`FLOWER_PATCHES` 几大片，再零星撒点野花；满地小草丛。花草几百棵，用 `InstancedMesh` 一次画完。
- **活起来**（`life.js`）：风吹树冠一阵大一阵小；每片花丛上一只蝴蝶飞 8 字，人走近（在走动时）会惊飞到高处，过几秒飞回来；池塘小溪里隔几秒跳起一条小金鱼，出水入水各溅一下。
- **碰一下会有反应**（`touch.js`）：只是好玩，不改进度也不进存档。
  - 脚步按小人走路动画算：腿按 `sin(phase)` 摆，`phase` 每过 π 就是一只脚落地。
  - 踩在踏脚石上：石头边溅起几颗水珠、一圈波纹往外散（`splashes.js`，一批波纹圈和水珠反复用），玩家踩还有水声；居民踩也溅，只是不出声。
  - 走在桥上（算上桥面伸到岸上那截）：左右脚高低不一样的“咚咚”声。
  - 撞到蘑菇屋的墙：菌盖压扁再弹回来，“啵嘤”一声，大屋子声音低；贴着墙不会一直弹，离开再撞才再弹。
  - 林子里几簇小红蘑菇（`TOADSTOOLS`，只是看的，和能捡的橙色小蘑菇不一样）：人走过去一个接一个弹。
  - 新音效在 `audio.js`：`splash()`、`plank(left)`、`boing(pitch)`、`flutter()`。
- 光是午后的：暖色的太阳从左前方斜照，影子往右后方拖。
- 整个森林大约 25 万个三角形（地面网格 5.6 万、侧面 3 万、花草 6 万），桌面上没问题，手机上还没实测。

### 👾 像素小镇 `pixel.js`

- `style: 'pixel'`：kit 自动把圆的都变成方的、细分降低、用平面着色。
- **渲染分辨率故意调低**：`main.js` 的 `applySize()` 里，像素世界把像素倍率降到 `min(0.6, 600 / 窗口宽)`，画布再加 CSS `image-rendering: pixelated` 放大，整个画面就是一格格的。
- 小人也会变成方块头（`Villager` 看 `kit.pixel`），玩家换一身像素配色。
- 草地是 20×20 的格子贴图，用 `NearestFilter` 不做平滑。

### ☔ 雨天伦敦 `london.js`

- 联排小楼、大本钟、双层巴士、黑色出租车、维多利亚路灯、红电话亭。
- `rain(w)`：520 根线段当雨丝一直往下落 + 地上溅起的小水圈；`ambient: 'rain'` 播雨声。
- `lightning(w)`：每隔十几二十秒打一次闪（亮-暗-亮两下，临时调高 `env.hemi` 的亮度）+ `sfx.thunder()` 雷声。
- 电话亭挂 `userData.peek`，点它往里看，太阳镜在里面。

### 🏖️ 海边假日 `beach.js`

- `SHORE = 1.6`：x 大于它是海。海水是半透明的水块，从侧面能看到水里游的鱼；海面是会起伏的网格，浪花沿岸边一进一退。
- 海里不能走（栈桥除外），用碰撞挡住。
- 椰子树、遮阳伞、毛巾、躺椅、沙堡（有护城河）、救生塔、栈桥和随浪摇的小船、冰淇淋车、海鸥、横着走的小螃蟹。
- `ambient: 'sea'`：海浪声。

### 🧪 地形测试 `terrain-test.js`

`?test=terrain` 打开，`&level=0.4` 换层高对比。一张有两层小山、一层高台、两层石台、池塘和桥的文字地图，用来试"一层 0.5 合不合适"、寻路会不会绕到台阶、崖边能不能挡住人。

## 4. 霓虹夜都：一个世界拆成一个文件夹

夜都是放大到 16×14、有地形、有完整剧情的"样板间"，`AGENTS.md` 里"按逻辑拆分世界"的规矩就是照它定的。`city/index.js` 的 `build` 读起来像目录：

```js
build(w) {
  w.terrain.build(w, { grass: groundColor, … }); // 地形（按区域上色）
  const power = createPower(w);                  // 电力
  buildSky(w, power);                            // 夜空、月亮的杆子
  const block = buildBlock(w, power);            // 中间的街区
  buildStreet(w, power);                         // 一圈马路、斑马线、路灯、公交站
  buildEdges(w, power);                          // 公园、花园、后巷、观景台
  const traffic = createTraffic(w, power);       // 车流
  const story = createStory(w, { power, block, traffic });   // 主线
  createTowerGame(w, { power, tower: block.tower, story });  // 俄罗斯方块彩蛋
  story.refreshLines();
}
```

模块之间通过返回的小对象通信（`power.turnOn()`、`block.alley.open()`、`traffic.start()`…），不共享局部变量。

### 电力 `power.js`

三路电，每路亮度 0→1 平滑过渡：

| 线路 | 由谁点亮 | 亮什么 |
|---|---|---|
| `sky` | 🌙 月亮挂回杆子 | 月光、星星、整体环境光，小巷看得见了 |
| `street` | 🚕 车流动起来 | 路灯 |
| `city` | 🎷 萨克斯响起来 | 楼的窗户、霓虹招牌、便利店 |

各处的灯用 `power.show(fn)` 登记"亮度变了怎么显示"；`power.windows(list, a)` 让一栋楼的窗户在电力到 `a` 时"啪"地亮起来，`a` 不同就一栋栋错开亮；`power.neon()` 管招牌，可以偶尔闪一下。

### 车流 `traffic.js` + `ring-road.js`

- 车道是一条闭合路径，车的位置就是"沿路径走了多远" `s`，每帧 `s += speed * dt`，`lane.pointAt(s)` 换算成坐标和行驶方向（`lane.project(x, z)` 反过来把一个点吸到车道上）。
- 速度取两个限制的较小值：**礼让**（前方 1 米内有人站在斑马线上就停）和**跟车**（离前车 1.5 以内就减速）。
- 停电时车停在 `jam` 位置，并登记两个 `blocker` 堵住主斑马线（撞上提示"左边好像有条缝"）；`start()` 后移走障碍。

### 居民 `people.js`

夜猫（加班的上班族，第一次打招呼）、阿霓（公交站等车）、老乔（BAR 门口，没萨克斯时垂头丧气 😢，拿回来就坐到凳子上吹 🎷）、老周（出租车司机，长椅上睡觉 💤，醒了以后上车消失），路通了以后来一个送外卖的小飞。台词按进度变：`refreshLines()` 在每次进度变化后重新给每个人配台词，台词本身就是给玩家的提示（"便利店后面那根高高的杆子上，本来挂着月亮的"）。

### 大楼俄罗斯方块 `tower-game.js`

来电后大楼正面一直在放待机演示；走到大楼门口按 E 开始玩（直接点楼只会走过去）。玩的时候围观的人越聚越多（先叫街上的熟人，不够就从街两头来路人），消行拍手，通关放烟花、全街欢呼，然后自动退出。

### 翻瓶子

`block.js`（后厨垃圾桶、售货机后面的缝）、`edges.js`（草丛、后巷大垃圾桶）、`street.js`（路灯脚下）里各自 `world.hideout()` 登记能翻的地方，打上标签 `kitchen` `bin` `bush` `deep` `lamp`。`layout.js` 的 `BOTTLE_HIDING` 规定：玻璃瓶 2 个只藏在后厨和土坡后面的深草丛，塑料瓶 4 个藏在垃圾桶、草丛、路灯脚下。每次进夜都重新随机藏。
