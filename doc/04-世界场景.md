# 04 · 世界场景

## 1. 一个世界的定义长什么样

`src/scenes/` 里每个世界导出一个普通对象（`def`）。以最简单的童话森林（`forest.js`）为例：

```js
export default {
  id: 'forest',                 // 唯一 id，存档里用它
  name: '童话森林',
  emoji: '🍄',
  style: 'toon',                // 材质风格：cozy / toon / pixel（见 kit.js）
  styleLabel: '童话风',          // 标题卡上的小字
  magnetStyle: 'toon',          // 冰箱贴的 CSS 样式（style.css 里 .magnet--toon）
  bg: 'linear-gradient(...)',   // 方块外面的背景（CSS）
  lights: {
    hemi: ['#e8f7ff', '#b5e39a', 1.9],      // 半球光：天空色、地面色、强度
    sun: ['#fffbe8', 2.6, [6, 12, 5]],      // 方向光：颜色、强度、位置
  },
  camera: { pos: [11.5, 11, 14.5], target: [0, 0.6, 0], fitH: 3, min: 2.5 },
  spawn: [0, 3.9],              // 玩家出生在哪 [x, z]
  greet: { name: '波波', text: '…' },   // 第一次进来谁主动打招呼
  next: 'pixel',                // 集齐 3 样后合成哪个世界的冰箱贴
  items: [                      // 要找的 3 样东西
    { id: 'coin', name: '像素金币', icon: '🪙', hint: '水面上的荷叶', make(kit) { return …THREE.Group } },
    …
  ],
  build(w) { … },               // 搭场景：摆模型、登记碰撞、放物品、放小人
};
```

### 全部可用字段

| 字段 | 必须 | 说明 |
|---|:-:|---|
| `id` `name` `emoji` `style` `styleLabel` `magnetStyle` `bg` `lights` `spawn` `next` `items` `build` | ✓ | 见上 |
| `camera` | ✓ | `pos`/`target` 定全貌的方向；`fitH` 全貌取景时后排要算多高；`min` 最近能拉多近；可选 `minPolar` `maxPolar` `minAz` `maxAz`（角度限制）、`startAz` `startPolar`（一进来的角度）、`fitSize`（全貌只框住一部分地面） |
| `greet` | | 对象，或 `(world) => 对象`（夜都按停电/修好说不同的话，`key` 不同各说一次） |
| `ambient` | | 环境声：`'rain'` `'city'` `'sea'` |
| `terrain` | | `{ map, level }` 有高低的地面；有了它，世界大小和边界都跟着地图走 |
| `size` / `bounds` | | 没有地形时自己定大小和可走范围（默认 10×10，±4.55） |
| `repairs` + `brokenGoal` | | 破败世界：要放回的东西 `[{ id, from, hint, msg }]`，`from` 是哪个世界带来的 |
| `materials` + `scatter` | | 这个世界能捡的材料和每次随机藏多少、藏在哪类地方 |
| `test` | | 测试场景，不写进存档的"当前世界" |
| `ending` / `comingSoon` | | 全家福结局 / 还没做好的世界（冰箱上点了提示"施工中"） |

### 注册

`src/scenes/index.js` 把所有世界放进 `SCENES`，并定好顺序：

```js
export const ORDER = ['home', 'forest', 'pixel', 'city', 'london', 'beach', 'finale'];
export const HOME = 'home';                                   // 家，不算冰箱贴
export const MAGNETS = ORDER.filter((id) => id !== HOME);      // 冰箱上的 6 块
export const WORLDS = ORDER.filter((id) => !SCENES[id].ending); // 真正能进去的
```

`finale`（全家福）不是一个世界，只是一个 `ending: true` 的冰箱贴定义，点开显示结局。

## 2. 世界链和物品的设计巧思

每个世界藏的 3 样东西，**都是下一个世界的"种子"**：

| 世界 | 风格 | 藏的 3 样 | → 合成 |
|---|---|---|---|
| 🏠 我的小屋 | cozy 动森风 | 🍄 红蘑菇、📖 童话书、⭐ 魔法星星 | 🍄 童话森林 |
| 🍄 童话森林 | toon 卡通着色 | 🪙 像素金币、❤️ 像素爱心、🎮 游戏卡带 | 👾 像素小镇 |
| 👾 像素小镇 | pixel 低分辨率 | 🌙 小月亮、🚕 小出租车、🎷 萨克斯 | 🌃 霓虹夜都 |
| 🌃 霓虹夜都 | cozy · 夜晚 | 🌂 红雨伞、🎩 绅士礼帽、🫖 红茶壶 | ☔ 雨天伦敦 |
| ☔ 雨天伦敦 | cozy · 雨天 | 🕶 太阳镜、🐚 扇贝壳、🏐 沙滩球 | 🏖️ 海边假日 |
| 🏖️ 海边假日 | cozy · 晴天 | ⭐ 海星、🪣 小水桶、📷 旧相机 | 🖼️ 全家福（结局） |

霓虹夜都更进一步：像素小镇带来的月亮、出租车、萨克斯，在夜都里是**要放回原处的零件**（修复点），而不是背包里的普通物品。

## 3. 各个世界

### 🏠 我的小屋 `home.js` + `home-exterior.js`

- 起点，也是唯一能自己改的地方。
- 只有后墙和左墙两面墙，镜头被限制在右前方斜着看（左右约 ±25°），转不到正对墙。
- **冰箱**：模型上每个网格都挂 `userData.action = 'fridge'`，点它或走近按 E 打开冰箱面板；`world.fridge` 存着它，别的地方用它的位置。
- **工作台**：左墙边，`w.interact('workbench', …)` → `env.openWorkbench(pick)` → 面板上选款式 → `decor.chooseDecor()` 扣材料、存档 → `room.applyDecor()` 换墙纸地板和外面的背景。
- `home-exterior.js`：墙顶的房檐和外面一圈花园（花、灌木、树、栅栏、小路）。只是看的，`bounds` 还是屋里那块地板，人走不出去。`size` 设成花园大小，`camera.fitSize` 只框住屋子。
- 居民：小橘（第一次打招呼）、阿绵。兴趣点：床边打盹 💤、看书 📖、晒太阳 ☀（`w.poi(...)`，小人闲逛时会随机走过去）。

### 🍄 童话森林 `forest.js`

最适合入门读的一个：一个文件 300 多行，从 `ground` → 蘑菇屋 → 树 → 花 → `build` 里依次摆池塘、蘑菇屋、高塔、空心木头、树、踏脚石、栅栏、花丛、萤火虫、物品、小人。

- 空心木头挂了 `userData.peek`，点它镜头会转到开口往里看——爱心就藏在里面。
- 卡带藏在高塔背后特别密的一圈花丛里，默认镜头看不到，要转过去。
- 花用 `rng(42)` 随机撒，跳过被挡住的位置；每次进来都一样。

### 👾 像素小镇 `pixel.js`

- `style: 'pixel'`：kit 自动把圆的都变成方的、细分降低、用平面着色。
- **渲染分辨率故意调低**：`main.js` 的 `applySize()` 里，像素世界把像素倍率降到 `min(0.6, 600 / 窗口宽)`，画布再加 CSS `image-rendering: pixelated` 放大，整个画面就是一格格的。
- 小人也会变成方块头（`Villager` 看 `kit.pixel`），玩家换一身像素配色。
- 草地是 20×20 的格子贴图，用 `NearestFilter` 不做平滑。

### 🌃 霓虹夜都 `city/`（重点）

见下面第 4 节。

### ☔ 雨天伦敦 `london.js`

- 联排小楼、大本钟、双层巴士、黑色出租车、维多利亚路灯、红电话亭。
- `rain(w)`：520 根线段当雨丝一直往下落 + 地上溅起的小水圈；`ambient: 'rain'` 播雨声。
- `lightning(w)`：每隔十几二十秒打一次闪（亮-暗-亮两下，临时调高 `env.hemi` 的亮度）+ `sfx.thunder()` 雷声。
- 电话亭挂 `userData.peek`，点它往里看，太阳镜在里面。

### 🏖️ 海边假日 `beach.js`

- `SHORE = 1.6`：x 大于它是海。海水是半透明的水块，从侧面能看到水里游的鱼；海面是会起伏的网格，浪花沿岸边一进一退。
- 海里不能走（栈桥除外），用碰撞挡住。
- 椰子树、遮阳伞、毛巾、躺椅、沙堡（有护城河）、救生塔、栈桥和随浪摇的小船、冰淇淋车、海鸥、横着走的小螃蟹。
- `ambient: 'sea'`：海浪声。

### 🧪 地形测试 `terrain-test.js`

`?test=terrain` 打开，`&level=0.4` 换层高对比。一张有两层小山、一层高台、两层石台、池塘和桥的文字地图，用来试"一层 0.5 合不合适"、寻路会不会绕到台阶、崖边能不能挡住人。

## 4. 霓虹夜都：一个世界拆成一个文件夹

夜都是放大到 16×14、有地形、有完整剧情的"样板间"，`AGENTS.md` 里"按逻辑拆分世界"的规矩就是照它定的。`city/index.js` 的 `build` 读起来像目录：

```js
build(w) {
  w.terrain.build(w, { grass: groundColor, … }); // 地形（按区域上色）
  const power = createPower(w);                  // 电力
  buildSky(w, power);                            // 夜空、月亮的杆子
  const block = buildBlock(w, power);            // 中间的街区
  buildStreet(w, power);                         // 一圈马路、斑马线、路灯、公交站
  buildEdges(w, power);                          // 公园、花园、后巷、观景台
  const traffic = createTraffic(w, power);       // 车流
  const story = createStory(w, { power, block, traffic });   // 主线
  createTowerGame(w, { power, tower: block.tower, story });  // 俄罗斯方块彩蛋
  story.refreshLines();
}
```

模块之间通过返回的小对象通信（`power.turnOn()`、`block.alley.open()`、`traffic.start()`…），不共享局部变量。

### 地图和布局 `layout.js`

**所有坐标都在这里**，别的文件只 import 名字（`TOWER`、`CROSSWALKS`、`LAMPS`…）。

```
z -7  背景高楼；右边观景台            '00000000000022<1'
z -6  后巷；台阶爬上观景台            '0000000000>>221^'
z -5  后马路                          '0000000000000000'
 …    街区（大楼、便利店、BAR）、前后人行道
z 1   前马路
z 3   马路对面的人行道
z 4   公园挡土墙，两处台阶            '11111111v11111v1'
      左边土坡、右边高台都是两层      '22<1111111>22111'
                                      '2211111111122111'
```

马路是一个圆角矩形环（`RING.outer` / `RING.inner`），两条车道各走一个方向；三条斑马线（前、左、后）是唯一能过马路的地方。

### 电力 `power.js`

三路电，每路亮度 0→1 平滑过渡：

| 线路 | 由谁点亮 | 亮什么 |
|---|---|---|
| `sky` | 🌙 月亮挂回杆子 | 月光、星星、整体环境光，小巷看得见了 |
| `street` | 🚕 车流动起来 | 路灯 |
| `city` | 🎷 萨克斯响起来 | 楼的窗户、霓虹招牌、便利店 |

各处的灯用 `power.show(fn)` 登记"亮度变了怎么显示"；`power.windows(list, a)` 让一栋楼的窗户在电力到 `a` 时"啪"地亮起来，`a` 不同就一栋栋错开亮；`power.neon()` 管招牌，可以偶尔闪一下。

### 主线 `story.js`

```
到达：全城停电，车堵在主斑马线上（左边留一条窄缝能挤过去），小巷黑着进不去
 │
 ├─ 🌙 月亮挂回便利店后面的杆子（太高，只能点）
 │     → sky 电力；小巷打开；红茶壶和一枚硬币出现
 │       （红茶壶在铁丝网后面，要绕到街区背面去拿）
 │
 ├─ 🪙 捡硬币 → 售货机投币 → ☕ 罐装咖啡 → 拿去跟睡着的司机老周说话 → 他醒了
 │
 ├─ 🚕 出租车放回停靠位
 │     出租车在 + 司机醒了 → 喇叭一响，车流动起来，斑马线通了，路灯亮
 │     → 🎩 礼帽出现（公园土坡后面的长椅上），送外卖的小哥出现
 │
 └─ 🎷 萨克斯还给老乔（要等月亮出来，不然他说"看不清谱子"）
       → city 电力：窗户、霓虹一栋栋亮；BAR 开门；爵士乐；🌂 红伞出现
全部修好 + 司机醒了 → 大家冒 🎉
```

剧情状态全在存档里：修复点在 `state.repaired.city`，硬币、咖啡、司机醒没醒、发现过哪些修复点在 `state.flags.city`。`loadProgress()` 里还处理了老存档（见 05 篇）。

### 车流 `traffic.js` + `ring-road.js`

- 车道是一条闭合路径，车的位置就是"沿路径走了多远" `s`，每帧 `s += speed * dt`，`lane.pointAt(s)` 换算成坐标和行驶方向（`lane.project(x, z)` 反过来把一个点吸到车道上）。
- 速度取两个限制的较小值：**礼让**（前方 1 米内有人站在斑马线上就停）和**跟车**（离前车 1.5 以内就减速）。
- 停电时车停在 `jam` 位置，并登记两个 `blocker` 堵住主斑马线（撞上提示"左边好像有条缝"）；`start()` 后移走障碍。

### 居民 `people.js`

夜猫（加班的上班族，第一次打招呼）、阿霓（公交站等车）、老乔（BAR 门口，没萨克斯时垂头丧气 😢，拿回来就坐到凳子上吹 🎷）、老周（出租车司机，长椅上睡觉 💤，醒了以后上车消失），路通了以后来一个送外卖的小飞。台词按进度变：`refreshLines()` 在每次进度变化后重新给每个人配台词，台词本身就是给玩家的提示（"便利店后面那根高高的杆子上，本来挂着月亮的"）。

### 大楼俄罗斯方块 `tower-game.js`

来电后大楼正面一直在放待机演示；走到大楼门口按 E 开始玩（直接点楼只会走过去）。玩的时候围观的人越聚越多（先叫街上的熟人，不够就从街两头来路人），消行拍手，通关放烟花、全街欢呼，然后自动退出。

### 翻瓶子

`block.js`（后厨垃圾桶、售货机后面的缝）、`edges.js`（草丛、后巷大垃圾桶）、`street.js`（路灯脚下）里各自 `world.hideout()` 登记能翻的地方，打上标签 `kitchen` `bin` `bush` `deep` `lamp`。`layout.js` 的 `BOTTLE_HIDING` 规定：玻璃瓶 2 个只藏在后厨和土坡后面的深草丛，塑料瓶 4 个藏在垃圾桶、草丛、路灯脚下。每次进夜都重新随机藏。
