# 06 · 宣传片模式（`?trailer`）

网址加 `?trailer`，游戏会按分镜自动演一遍小屋和霓虹夜都（约一分钟），连现场合成的音效一起录成 1080p 视频。代码全在 `src/trailer/`，平时玩不会加载（`main.js` 里是 `await import('./trailer/index.js')`）。

## 怎么接进游戏

`main.js` 的 `startTrailer()` 交出一组接口给宣传片模块，宣传片不直接碰 `main.js` 的内部变量：

```js
runTrailer({
  renderer, camera, controls, zoom: ZOOM,
  get world() { … }, get player() { … },   // 当前世界、玩家
  loadScene, loop, collect, doRepair,      // 换世界、开始循环、捡东西、放回东西
  setRenderSize(size) { … },               // 固定渲染尺寸（不跟窗口走）
  setDirector(next) { … },                 // 交出镜头：有导演时每帧调 director.update() 而不是 updateCamera()
});
```

`frame()` 里只多了两处：镜头交给 `director.update(dt)`；画完一帧调 `director.afterRender(canvas)`（WebGL 画布下一帧就清空，要在同一帧里拷走）。

## 各文件分工

| 文件 | 干什么 |
|---|---|
| `index.js` | 入口。`useMemorySave(TRAILER_SAVE)` 换成内存存档 → 渲染固定 1920×1080 → 页面上只露出预览画布和一个小面板 → 点"开始录制"（这一下点击让浏览器允许出声）→ 建导演、开录 → 演完停录 → 交付视频 |
| `shots.js` | **分镜表** `SHOTS` 和起始进度 `TRAILER_SAVE`。改宣传片主要改这里 |
| `director.js` | 导演：按分镜一个个镜头推进；换世界；到点触发 `cues`；在 `from` / `to` 两个机位之间慢进慢出地插值；叠字幕、标题卡、黑场 |
| `overlay.js` | 画在画面上的字幕条、标题卡、黑场，按 1080p 设计、按高度等比缩放 |
| `backdrop.js` | 游戏里方块外面的背景是 CSS 渐变，3D 画布本身透明；录视频只录画布，所以要把同样的渐变自己画进去。只认游戏里用到的 `radial-gradient` / `linear-gradient` 两种写法，别的直接报错 |
| `recorder.js` | 每帧把 背景渐变 + 3D 画面 + 字幕 叠到一块画布上，`captureStream` + `MediaRecorder` 连声音一起录。优先 MP4，不行 WebM，码率 16Mbps |

## 分镜表的写法

真实的一个镜头（`shots.js` 里的「挂回月亮」）：

```js
{
  name: '挂回月亮',
  duration: 6,                                  // 秒
  caption: '把丢掉的东西，放回原来的地方',        // 字幕（相邻镜头一样就连着显示）
  cues: [                                        // 到点触发的剧情
    { at: 0.5, run: (stage) => stage.discover('moon') },
    { at: 2.2, run: (stage) => stage.repair('moon') },
  ],
  camera: {                                      // 两个机位，中间慢进慢出地过渡
    from: { look: [MOON[0], MOON[1] - 1.2, MOON[2]], distance: 9.5, polar: 1.12, azimuth: CITY_AZIMUTH - 0.3 },
    to: { look: [MOON[0], MOON[1] - 1.6, MOON[2] + 0.5], distance: 12, polar: 1.05, azimuth: CITY_AZIMUTH - 0.1 },
  },
},
```

其他可选字段：`world`（在哪个世界拍，和上一个不同就换世界，方块重新落下来；没写就沿用上一个）、`setup(stage)`（开拍前的准备，比如把人挪到哪）、`fadeIn` / `fadeOut`（黑场秒数）、`title: { title, subtitle, at, fade }`（标题卡）。机位里的 `distance` 和游戏里镜头距离写法一样，会再乘上窄视野的换算系数。

`stage` 是导演给分镜用的小工具：`place`（瞬移人）、`walk`（让人寻路走过去）、`playerPoint`（镜头跟人用）、`discover` / `repair`（和玩家操作效果一样，剧情照常走）、`useWorkbench(kind, id)`（拍换壁纸时不弹面板，直接选那一款）、`sound`。

现在的 11 个镜头：小屋落下 → 找亮晶晶的东西 → 换壁纸 → 去冰箱 → 停电的夜都 → 挂回月亮 → 出租车回来 → 过斑马线 → 萨克斯响起 → 大楼俄罗斯方块 → 片尾。

夜都的坐标从 `scenes/city/layout.js` 拿；小屋的冰箱、工作台从搭好的世界里读（`world.fridge`、`world.interacts.get('workbench')`）。

## 起始进度 `TRAILER_SAVE`

从一份写好的进度开始演：冰箱上已经有夜都；夜都还停着电；司机已经喝过咖啡醒着（片子里不演买咖啡这段，出租车一回来车就开）；背包里瓶子够做星空壁纸和胡桃木地板；打过招呼了，不会有人跳出来挡镜头。

## 视频存到哪

- 开发服务器上：`fetch('/__trailer/save?name=…', { method: 'POST', body: blob })`，`vite.config.js` 里的 `saveRecordings()` 插件把它写进项目的 `recordings/`（文件名只允许字母数字加 `.mp4` / `.webm`）。
- 不是开发服务器（比如线上）：面板给一个下载链接。

## 注意

按**真实时间**录（声音是现场合成的，只能实时录）：录的时候窗口要一直在前台、别被挡住，不然浏览器会降速，画面掉帧。
