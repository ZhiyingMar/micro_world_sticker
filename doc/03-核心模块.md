# 03 · 核心模块

按"从底层到上层"的顺序讲：先是造东西的工具，再是世界和小人，最后是界面、音效这些外围。

---

## kit.js —— 造型工具箱

所有模型都是用代码拼的。`Kit` 提供一套积木，**同一段造型代码在不同风格的世界里会自动换材质**：

| 风格 `style` | 材质 | 用在 |
|---|---|---|
| `cozy`（默认） | `MeshStandardMaterial`，粗糙度 0.82 | 小屋、夜都、伦敦、海边 |
| `toon` | `MeshToonMaterial` + 3 级灰度渐变贴图 → 一块块的卡通明暗 | 森林、地形测试 |
| `pixel` | `MeshLambertMaterial` + `flatShading`，而且几何细分降到 1/4、圆角方块变直角方块 | 像素小镇 |

积木方法：`box(w, h, d, color, 圆角)`、`sphere`、`dome`（半球，蘑菇盖/头发）、`cyl`、`cone`、`torus`、`star`、`pixelArt(rows, palette)`（用字符画拼像素物件，同色的小方块合并成一个网格）、`mesh(geometry, color)`。全部默认投影、接收阴影。

其他导出：

- `makeMat(style, color, opts)`：**按 风格+颜色+参数 缓存材质**，同色的东西共用一份材质。所以改一个材质会连带改到所有同色的东西——要单独改的（比如变半透明）得先 `clone()`。`isSharedMaterial()` 用来判断。
- `rng(seed)`：可复现的随机数。花草、石头的位置用它撒，每次进世界都一样。
- `at(obj, x, y, z, ry)`：设位置、朝向的小帮手，造型代码里到处在用。
- `facade(cols, rows, …)`：画楼房立面，返回白天的 `map` 和只有亮窗的 `emissive` 两张贴图（夜都的楼靠它"一扇扇亮起来"）。
- `canvasTexture(w, h, draw)`：在一块 canvas 上画东西，变成贴图。地砖、草地、壁纸都是这样现画的。

## fx.js —— 特效

- `Sparkles`：闪光粒子系统。`world.fx.emit(位置, { count, color, size, rise… })` 冒一把星星，自己飘、缩、消失。
- `makeBubble()` / `bubbleTexture(text)`：小人头顶的表情气泡（`♪ … 💤 🎉`），按文字缓存贴图。
- `glow(color, size)`：加法混合的光晕精灵，路灯、霓虹、月亮外圈用。
- `neonText(text)`：自发光的招牌文字贴图。
- `makeMotes()`：萤火虫/光点。
- `softDotTexture()`：共用的一张中间亮、往外淡的白色圆点贴图（小屋的灰尘、热气用）；是共用的，不要登记进 `world.texture`。
- `makeStarField()`：方块后面一层球壳里撒的 3D 星空（小屋"夜都星空"壁纸用），三层亮度、分组闪烁。
- `blobShadowTexture()`：方块底下那块软阴影。

## terrain.js —— 有高低的地面

用一张**文字地图**描述地形，每个字符一格 1×1：

```
'0'-'9'   高度层，一层默认 0.5（约半个人高）
'~'       水，比 0 层低一层，走不过去
'=' '|'   横桥 / 竖桥
'o'       踏脚石：和桥一样是 0 层、下面是水，画成一块石头，没有栏杆
'> < ^ v' 台阶，箭头指向"往上走"的方向
```

例子（霓虹夜都下面三行，公园挡土墙和两个台阶）：

```js
'11111111v11111v1',
'22<1111111>22111',
'2211111111122111',
```

`Terrain` 提供：

- `heightAt(x, z)`：这里的地面多高。台阶在逻辑上是一段平滑斜坡。
- `straddles(x, z, r)`：半径 r 的人站在这里会不会跨在崖边上（周围 8 个点和中心高度差超过 0.2 就算），`World.blocked()` 用它挡住人。
- `bounds`：按地图大小算出的可走范围。
- `isPlainGround(x, z)`：这里是不是普通平地（不是水、桥、踏脚石、台阶），撒花、铺石板时用。
- `build(world, colors)`：**占位外观**——每格一根土柱子，顶上一层草皮，台阶切成 4 级，水和桥。`grass` 可以是函数，按格子返回颜色（夜都的人行道、公园、后巷颜色不一样）。

**逻辑和外观分开**：`heightAt` 只看地图；`build` 只是照着地图摆方块。以后换成建模的地形块，逻辑不用动（规格见 `TODO.md` 第 0 条）。

### terrain-soft.js —— 圆润的地形外观

`build` 的方块一眼就是格子地图，适合夜都这种方方正正的城市；童话风的世界用 `buildSoftTerrain(world, look)`：

- 整个地面是一张网格（每单位 12 段），按 `heightAt` 取高度再做两遍 [1, 2, 1] 模糊，崖边和拐角就圆了。圆角只在崖边 ±0.17 以内，人离崖边最近也有 0.22，所以人脚下的地面和逻辑高度对得上。
- 桥、踏脚石旁边的岸不磨圆（算岸的时候把它们当平地），不然人从岸上走过去会踩空。
- 平的地方是草（颜色由 `look.grass(x, z, level)` 每个顶点给一次，森林用它画深浅和土路），陡的地方露出一层层的土，水下是水底色，水线上一圈浅色。
- 水是整个方块上一张水面（被地挡住的地方看不见），波纹贴图慢慢挪；水面比 0 层低 0.4 层，踏脚石、桥、岸都露出水面一截。
- 台阶画成嵌在草坡里的石板，踏脚石是扁扁的凹凸石头，桥有木板、横梁、桥桩和扶手。
- 返回 `{ waterSurface, heightAt }`：水面多高、画出来的地面多高。

目前用了地形的世界：霓虹夜都、童话森林、地形测试场景。其他世界是平地（`world.heightAt` 直接返回 0），大小写死 10×10。

## world.js —— 一个世界的容器

`new World(def, env)` 做的事：

```
constructor
 ├─ kit = new Kit(def.style)；root = new Group()
 ├─ terrain（def.terrain 有的话）；size、bounds 从地形或 def 来，默认 10×10、±4.55
 ├─ 一堆登记表：colliders、items、hiddenItems、repairs、interacts、hideouts、fadeables、games、pois、updaters
 ├─ complete = 这个世界的物品是不是都找齐了（老存档的破败世界直接当作修好了）
 ├─ def.build(this)                    ← 世界文件在这里搭场景
 ├─ 存档里修好过的修复点：repair(id, instant=true) 直接恢复，不播动画
 └─ def.scatter 有的话：hideMaterials() 把材料随机藏进能翻的地方
```

世界文件在 `build(w)` 里调用的 API，按用途分组：

### 摆东西 & 碰撞

| 方法 | 作用 |
|---|---|
| `add(obj, x, y, z, ry)` | 把东西放进世界 |
| `solid(obj, pad)` | 把物体的包围盒登记成方形障碍 |
| `solidCircle(x, z, r)` | 圆形障碍（树干、蘑菇屋） |
| `blocker(minX, maxX, minZ, maxZ, say)` | 可以被移走的障碍，`say` 是人撞上时的提示（"🚗 车都堵在这儿…"），之后 `unblock(c)` 移走 |
| `heightAt(x, z)` | 地面高度，摆东西时 `y` 用它，别写死 0 |
| `onUpdate(fn)` | 每帧回调 `fn(dt, t)`：动画、车流、电力都靠它 |
| `texture(tex)` | 登记贴图，切世界时一起释放 |

碰撞判定 `blocked(x, z, r, self)`：出界 → 跨崖边 → 撞方形/圆形障碍 → （传了 self 时）撞到别的小人。撞人时有个细节：**已经重叠的话允许往远离的方向走**，免得两个人卡死在一起。

### 物品

| 方法 | 作用 |
|---|---|
| `placeItem(id, x, y, z, { spin, hidden })` | 放一个要收集的物品（模型来自 `def.items` 里的 `make(kit)`）。已经找到的不放。外面套一个看不见的球当点击范围（小东西不好点） |
| `revealItem(id)` | `hidden: true` 的物品要等某件事发生才出现（夜都：修好月亮 → 红茶壶出现） |
| `placeThing(id, obj, …, { icon, name })` | 小道具（硬币、咖啡）：不算 3 样收集物，捡起来记一个 flag，用来推进剧情 |

### 互动

| 方法 | 作用 |
|---|---|
| `interact(id, obj, x, z, { reach, label, icon, available, fn })` | 能互动的东西（售货机、工作台）。站在 (x, z) 附近 `reach` 内按 E 就调 `fn`；`available()` 返回 false 时先不出现 |
| `hideout(id, obj, x, z, { tags, name, show, … })` | 能翻找材料的地方（垃圾桶、草丛、路灯脚下）。本质上是登记了一个 `interact`。`show` 决定藏的东西露不露：`inside` 看不见、`peek` 斜插着露个瓶口、`open` 躺在地上 |
| `hideMaterials(groups)` | 按 `def.scatter` 每次进来随机藏，比如 `{ material: 'glass', count: 2, from: ['kitchen', 'deep'] }` |
| `game(id, obj, { view, entrance, can, start, stop, key, update })` | 点一下能玩的小游戏。有 `entrance` 的，点它只会走过去，站到入口才开始（防止转镜头时误触） |
| `villager(opts, x, z)` | 放一个小人 |
| `poi(x, z, { emote, face, sit, dur })` | 兴趣点：小人闲逛时会随机走过去，面朝某个方向，冒个表情，待一会儿（坐下喝茶、看书、钓鱼…） |
| `fadeable(obj)` | 登记一栋楼：挡住人时变半透明（见 `occlusion.js`） |

### 破败世界：修复点

| 方法 | 作用 |
|---|---|
| `repairSpot(id, spot, x, y, z, { reach, seeR, can, fn })` | 缺东西的地方。`spot` 一般是 `ghostify(模型)` 做的半透明虚影。一开始看不见，人走到 `seeR` 内（或镜头凑近）才"发现"它 |
| `discover(id)` | 发现：虚影显现，记 `seen:id` 标记 |
| `repair(id, instant)` | 放回去：移掉虚影，记进存档，调 `fn(instant)`（亮灯、开路、让东西出现）。`instant` 表示读档恢复，不播动画 |
| `can()` | 返回 `true` 能修；返回 `{ name, text }` 表示还不行，由谁说什么（老乔：天这么黑看不清谱子） |
| `flag(name)` / `setFlag(name)` | 这个世界的其他进度标记（`coin`、`coffee`、`driver`…） |
| `whenRestored(fn)` / `fullyRepaired` / `extraDone` | 全部修好的那一刻。世界可以加额外条件（夜都：还要司机醒了） |
| `bag()` | 背包里还没用掉的小道具，目标栏显示用，世界自己覆盖 |

### 寻路 `findPath(sx, sz, tx, tz, r, avoid)`

- 把可走范围切成 **0.1 × 0.1** 的小格（夜都停电时斑马线边上那条窄缝才走得过去），每格是否可走懒计算（用到才调 `blocked()`）。
- **8 方向 A\***，自己写的二叉堆；斜着走时要求两边都是空地，不会擦着墙角穿过去。
- 起点/终点被障碍盖住时，往外一圈圈找最近的空地（终点找 20 圈：点在桌子上也能走到桌边）。
- 最后**拉直**：从当前点出发，能直线走到（`lineClear`）的最远路点就直接跳过去，折线变成几段直线。
- 只看固定障碍。玩家被小人堵住时会带上 `avoid` 再算一次，把其他人也当障碍。
- 有高低的世界里，崖边被 `blocked` 挡住，所以寻路自然会绕到台阶上去。

## villager.js —— 小人

一个 `Villager` 既可以是居民，也可以是玩家（`controlled: true`）。

**外形** `buildBody(look)`：腿、身子、胳膊、头、头发、眼睛、腮红，像素世界里全换成方块。腿和胳膊挂在单独的 pivot 上，方便摆动。帽子 `hat`：`gnome` 尖帽、`leaf` 叶子、`bow` 蝴蝶结、`mushroom` 蘑菇头、`cap` 鸭舌帽、`tophat` 礼帽、`busby` 卫兵熊皮帽、`beanie` 毛线帽；`umbrella` 撑伞（伦敦）。

**移动** `moveToward(tx, tz, dt, speed)`：往目标走一步；正前方被挡住时，按 0、±0.45、±0.9、±1.35 弧度依次试着偏转绕过去（偏向固定的一侧，不来回抖），都不行就累计 `stuck`。

**居民的日常 AI**（状态机）：

```
idle ──计时到──► chooseNext()
                  ├─ 55% 概率挑一个空着的兴趣点 → walk（目标是兴趣点）
                  └─ 否则随机走 1~4 远 → walk
walk ──算一次路（findPath），沿路点走──► 到了
                  ├─ 有兴趣点 → act（转向、冒表情、可能坐下，待 dur 秒）
                  └─ 没有 → idle（30% 冒个随机表情 ♪ … ✿ ? ♥）
     ──卡住超过 0.8 秒──► 放弃，idle
act ──计时到──► idle
talk：被玩家搭话，原地站着（坐着的不站起来，只转头），聊完接着做刚才的事
```

`pin({ emote, sit, face })` 把小人钉在原地一直做一件事（司机睡觉 💤、老乔难过 😢），`unpin()` 放开。

**玩家操控** `control(dt, input)`：有键盘/摇杆输入就按镜头朝向直接走；没有就沿 `goTo()` 算出的路线一段段走；被人堵住（卡住 0.6 秒）就带上 `avoid` 重新绕一次。

**台词**：`lines` 数组轮流说；也可以挂 `onTalk()` 根据进度返回不同的话（夜都的司机老周）。

**每帧** `update()`：AI 或操控 → 朝向平滑转过去 → 脚踩在 `heightAt` 上 → 走路时腿和胳膊摆动、身子上下颠 → 头轻轻晃 → 气泡计时。

## occlusion.js —— 挡住人的楼变半透明

镜头能随便转，人经常走到楼后面看不见。每帧从镜头往人身上两处（脚边 0.3、头顶 1.1）打射线，碰到登记过 `world.fadeable()` 的楼就让它淡到 22% 透明度（淡下去时不写深度，后面的东西才画得出来），走开了慢慢恢复。第一次淡时记下材质原来的透明度，恢复时还原。

另外 `main.js` 里还有一层"剪影"：玩家身上的材质写模板缓冲，再加一个只在"被挡住"处画的半透明黄色剪影（`depthFunc: GreaterDepth` + 模板测试），被树、房子挡住时也能看到人在哪。

## ui.js —— 界面

一个 `ui` 对象，所有 DOM 操作都在这里，`main.js` 只调它的方法：

- `setScene(def)`：标题卡、`body` 上的 `style-xxx` 类、背景、目标栏、材料栏。
- `renderGoal(def, { broken, bag })`：底部 3 个格子。普通世界显示"找到这些东西"+ 3 个问号（悬停看提示 `hint`）；破败世界显示 `brokenGoal` + 要放回的东西 + 背包小道具。完成的格子打勾淡出，全完成整栏收起。
- `toast` / `say`（对话框）/ `speech`（打招呼气泡）/ `prompt`（底部「E 聊天」）/ `tooltip` / `action`（手机互动按钮）。
- `openFridge(onPick)`：画冰箱上的冰箱贴（没解锁的显示"?"，新的有 NEW!，当前的有 📍）。
- `openWorkbench(onPick)`：工作台面板，壁纸/地板两个页签，每款显示小样、状态（使用中/做过了/配方，缺几个）。
- `combine(def, next)`：合成动画（三样东西转圈聚拢 → 闪光 → 冰箱贴出现 → 点按钮）。
- `showGame` / `hideGame`：小游戏界面，按住方向键连发，连按三下 ↓ 一落到底。
- `showEnding()`：结局拍立得，统计、名单、"从头再玩"。
- `intro()`：第一次进游戏的说明卡，鼠标和触控两套说明。

## audio.js —— 合成音效

**没有任何音频文件**。`sfx.pickup()`、`fanfare()`、`repair()`、`jazz()`（夜都萨克斯回来时的一小段摇摆爵士）、`horn()`、`thunder()` 等全是用振荡器 `tone(频率, 开始, 时长, 波形)` 现场合成的。环境声（雨、城市、海浪、森林、小屋）是一段循环的粉红噪声过高通/低通滤波，海浪再加一个 0.12Hz 的慢振荡让音量一涨一落；森林和小屋隔一会儿有鸟叫。碰一下的反应音：`splash()` 踩水、`plank()` 桥上脚步、`boing()` 蘑菇弹、`flutter()` 蝴蝶惊飞，小屋里的 `puff()` 踢毛线球、`footstep()` 木地板/地毯上很轻的脚步、`meow()` 猫叫。

浏览器要求先有一次用户点击才能出声，所以 `pointerdown` 时调 `sfx.unlock()`。静音状态存在 `state.muted`。

## decor.js —— 小屋装修

壁纸 4 款、地板 4 款，每款就是一条数据：`{ id, name, cost: { plastic: 3 }, paint(context, w, h), backdrop, wainscot }`。`paint` 在 canvas 上画一块能平铺的图案。

- `chooseDecor(kind, entry)`：没做过的先扣材料做出来，然后换上，存进 `state.decor`。返回 `'switched' | 'crafted' | 'short'`。
- `currentDecor(kind)`：现在用的是哪款；存档里的款式被删了会退回默认款并 `console.warn`。
- 小屋的 `buildRoom()` 返回一个 `applyDecor(kind, entry)`，换墙纸贴图、墙裙颜色、外面的背景（`world.setBackdrop()`），"夜都星空"款还会在小屋外围加一圈 3D 星星。

## tetris.js —— 大楼俄罗斯方块

简化版俄罗斯方块逻辑（7 种块、七个一袋洗牌出块、贴墙转不过去时左右挪一挪再试、消行），特别的是**画在两张 canvas 上**：一张是窗户的样子（`map`），一张只有亮着的格子（`emit`），作为贴图贴到夜都大楼正面，每扇窗户就是一格。底下留 3 行当大堂不放方块。`demo: true` 是待机演示，自己乱落块、不出声，告诉路过的人"这栋楼能玩"，堆到一半高就清空重来。真正玩的时候累计消掉 4 行就通关。
