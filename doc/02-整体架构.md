# 02 · 整体架构

这一篇从 `index.html` 一路讲到每一帧在干什么。看的时候建议同时打开 `src/main.js`。

## 1. 页面骨架

`index.html` 里只有一块全屏的 `<canvas id="c">`，以及叠在上面的一堆 DOM 元素：

| 元素 | 作用 |
|---|---|
| `#hud` | 左上标题卡（世界名、风格、材料数）、右上按钮（冰箱/回家、全貌、全屏、声音）、底部目标栏（3 个格子）、操作提示、触控摇杆和互动按钮 |
| `#game` | 小游戏界面（夜都大楼俄罗斯方块）：顶栏、帮助、手机上的十字键 |
| `#tooltip` / `#speech` / `#dialog` / `#toast-layer` | 鼠标悬停提示、小人主动打招呼的气泡、聊天对话框、飘过的小提示 |
| `#fridge` / `#workbench` / `#combine` / `#intro` / `#ending` | 全屏面板：冰箱、工作台、合成冰箱贴动画、开场说明、结局 |
| `#fade` | 切换世界时的淡入淡出 |

**3D 画面和界面是分开的**：3D 全在 canvas 里，按钮、面板全是普通 HTML + CSS（`ui.js` 管）。canvas 背景透明，方块外面那一大片背景是 CSS 渐变（`#app` 上的 `--scene-bg` 变量）。

## 2. 启动流程（`main.js` 末尾）

```
加载 main.js
 ├─ 建 WebGLRenderer（开阴影、开 stencil，透明背景）
 ├─ 建 Scene、PerspectiveCamera（视野 20°）、OrbitControls
 ├─ 建两盏灯：半球光 hemi + 方向光 sun（投影）；方块底下一块软阴影 blob
 ├─ 绑好所有输入事件（指针、键盘、摇杆、按钮）
 ├─ ui.setHint(); syncTouchUI();
 └─ 网址有 ?trailer ？
      ├─ 有 → startTrailer()：动态 import('./trailer/index.js')，交出一组游戏接口，导演接管
      └─ 没有 → startPlaying()
            ├─ loadScene(上次所在的世界 / ?test=terrain 的测试场景 / 默认 home)
            ├─ loop()  开始每帧循环
            └─ 第一次玩：ui.intro() 显示开场说明 → 关掉后 maybeGreet()（小人主动打招呼）
```

## 3. 加载一个世界：`loadScene(id)`

```
loadScene(id)
 ├─ def = SCENES[id]
 ├─ 旧世界 world.dispose()，清掉玩家、对话
 ├─ world = new World(def, env)          ← 搭场景就发生在这里（见 03 篇）
 │     env = { hemi, sun, toast, onChange, onMaterial, startGame, onBackdrop, openWorkbench }
 ├─ scene.add(world.root)
 ├─ 按 world.size 缩放底部软阴影、阴影相机范围
 ├─ 按 def.lights 设两盏灯的颜色、强度、方向
 ├─ world.whenRestored(...)              ← 破败世界修好时放礼花 + 提示
 ├─ ui.setScene(def, world.backdrop)     ← 标题卡、背景、目标栏
 ├─ sfx.ambient(def.ambient)             ← 雨声 / 城市 / 海浪
 ├─ 按 def.camera 限制镜头的上下左右角度、远近；defaultView() 算出"全貌"机位
 ├─ state.current = id; save()
 ├─ spawnPlayer()：在 def.spawn 放一个 controlled 的 Villager，名字"你"，加上被挡住时的剪影
 ├─ 镜头放到人身边，斜着往下看
 └─ intro = { t: 0 }：方块从很小"弹"出来落下的动画
```

切世界走的是 `travel(id)`：`busy` 锁住操作 → 淡出 → `loadScene` → 淡入 → 弹提示。

## 4. 每一帧：`frame(dt)`

`loop()` 用 `requestAnimationFrame` 不停调 `frame(dt)`，`dt` 封顶 0.05 秒（切到后台再回来不会一下子跳很远）。

```
frame(dt)
 ├─ 方块落下的开场动画（intro）；落定后 maybeGreet()
 ├─ world.update(dt, t, input)
 │     ├─ 每个居民 villager.update()（日常 AI：闲逛、去兴趣点坐下、发呆）
 │     ├─ 物品上下浮动、自转、偶尔冒闪光
 │     ├─ 修复点虚影呼吸闪烁
 │     ├─ 世界自己登记的 onUpdate 回调（车流、电力、旗子飘、雨…）
 │     └─ 粒子 fx.update()
 ├─ 玩家：
 │     ├─ input.yaw = 镜头的水平角 → 方向键"上"永远是朝屏幕里走
 │     ├─ player.update()（键盘/摇杆移动，或者沿着点击算出的路线走）
 │     ├─ 走到物品 0.8 以内 → collect(id) 自动捡起
 │     └─ nearestInteractable()：附近能互动的东西 → 底部提示「E 和 xx 聊天」、手机上的互动按钮
 ├─ checkDiscover()：走近或镜头凑近修复点 → 发现它（虚影显现）
 ├─ anims：捡起物品时"弹走"的小动画
 ├─ 小游戏在玩 → game.g.update(dt)
 ├─ 镜头：宣传片模式下 director.update()，平时 updateCamera()
 ├─ updateOccluders()：挡住人的楼变半透明
 ├─ updateGreeting()：打招呼气泡跟着小人头顶
 ├─ updateHover()：鼠标悬停提示
 └─ renderer.render(scene, camera)；宣传片模式下把这一帧交给录像
```

## 5. 一次"捡东西"的完整链路

以在童话森林点池塘荷叶上的金币为例：

1. **按下/抬起**：`pointerdown` 记下位置和时间；`pointerup` 时如果手指没怎么动（鼠标 7px、触控 12px 内）、不到 0.5 秒、不是双指，就算一次点击 → `handleClick(x, y, touch)`。
2. **点到了什么**：`pick()` 从镜头打一条射线进 `world.root`，跳过粒子、雨丝、看不见的、半透明的东西，从被碰到的网格往上找父节点上的标记：
   - `userData.itemId` → 物品；`userData.repair` → 修复点；`userData.interact` → 互动物；`userData.game` → 小游戏；`userData.villager` → 小人；`userData.action === 'fridge'` → 冰箱；都没有 → 地面。
   - 触控时没点中东西，会用 `pickNear()` 在手指附近 34px 内找物品/小人（手指比鼠标粗）。
3. **走过去**：离金币超过 1.6 → `player.goTo(x, z)`，内部 `world.findPath()` 用 A* 算一条绕开障碍的折线。
4. **自动捡起**：每帧检查，人离物品 < 0.8 → `collect('coin')`。
5. **collect**：
   - 从 `world.items` 里删掉，`foundIn('forest').push('coin')`，`save()` 写进 localStorage；
   - 音效、闪光粒子、物品弹走动画、目标栏那一格打勾淡出、提示「找到了 🪙 像素金币！」；
   - 如果 3 样都齐了 → 1.3 秒后 `runCombine(def)`。
6. **合成**：`state.magnets.push('pixel')`、`state.newMagnet = 'pixel'` → `ui.combine()` 播三样东西转圈合成冰箱贴的动画 → 点"贴到冰箱上" → `openFridge()`。
7. **冰箱**：点一块冰箱贴 → `travel(id)` 去那个世界；点"全家福" → 结局画面。

## 6. 镜头怎么工作

镜头用的是 Three.js 自带的 `OrbitControls`（拖动旋转、滚轮/双指缩放、`zoomToCursor` 朝鼠标指的地方放大），`main.js` 在它上面加了几层自己的规矩：

- **2.5D 感**：视野只有 20°、拉得很远，透视变形小，像在看一个小立体模型。原来的距离是按 32° 调的，所以所有距离都乘上 `ZOOM` 换算系数。
- **角度限制**：上下只能在"斜着看"的一段里转（默认 `DEFAULT_TILT = [0.65, 1.25]` 弧度），世界可以用 `camera.minPolar / maxPolar / minAz / maxAz` 自己定（小屋只有两面墙，左右只能转约 ±25°）。
- **远近限制**：最远就是"全貌"——`defaultView()` 用二分法找一个距离，让方块的地面和后排高处刚好塞进界面元素之间的空白（`safeArea()` 量了标题卡、按钮、目标栏占掉的边）。
- **不一直跟人**：`followPoint()` 把人投影到屏幕上，只有人走到空白区域边上（`FREE_LOOK_EDGE = 0.8`）才开始把镜头挪回人身上，挪到人回到中间附近（`0.3`）为止。这样放大看别处时镜头不会被人拽走。
- **拉远时慢慢转向方块中心**：越接近全貌距离，镜头中心越偏向整个方块的中心。不跟人时镜头会一直偏到对准中心，所以停止跟人之前先算偏过去以后人在哪（`settledOffCenter()`）：会被推到边上（超过 `0.8`）就一直跟着人，人离边还有 `OVERVIEW_DRIFT_EDGE = 0.7` 以内才停止跟人。不这样的话，拉远一点时"停止跟人 → 偏向中心 → 人被推到边上 → 又跟人"会一直循环，人在画面上来回晃。
- **往里看（peek）**：电话亭、空心木头这种模型上挂了 `userData.peek = { target, from }`，点它时镜头飞到开口处往里看（`hold = true`，人一动才恢复跟随）。
- **小游戏**：玩俄罗斯方块时关掉 OrbitControls，镜头飞到正对大楼的位置（避开顶栏和十字键），结束后飞回原处。

## 7. 输入

| 输入 | 处理 |
|---|---|
| 鼠标/手指点 | `handleClick`：点哪走哪，够近就互动 |
| WASD / 方向键 | `input.up/down/left/right` → `player.control()` 按镜头朝向换成世界方向 |
| 虚拟摇杆（触控） | `input.ax/az`，模拟量，推得越远走得越快 |
| E / 空格 / 回车，或手机互动按钮 | `nearestInteractable()` 找最近的：修复点 > 互动物（挑最近的）> 小人 > 冰箱 |
| Esc | 关面板、结束对话；玩小游戏时退出 |
| 小游戏里的方向键/空格 | `GAME_KEYS` 转成 left/right/rotate/down/drop |

触控/鼠标模式会自动切换：碰到触摸就切到触控界面（显示摇杆、互动按钮，渲染倍率降到 1.5），用鼠标就切回去。

## 8. 几个"锁"

`main.js` 用几个变量防止状态打架：

- `busy`：合成动画、切世界期间，点击、按键、捡东西都不响应。
- `ui.panelOpen`：冰箱、工作台开着时不响应 3D 里的点击。
- `ui.dialogOpen`：聊天时，再点一下/按键就是关对话。
- `game`：玩小游戏时键盘全给游戏。
- `hold`：往电话亭里看时镜头不跟人。
