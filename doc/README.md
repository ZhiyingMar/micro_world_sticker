# 冰箱贴小世界 · 代码导读

这一组文档讲这个项目的代码是怎么组织、怎么跑起来的，适合从头慢慢看。写于 2026-10-20（`feature/gameplay` 分支，提交 `0e0d34c` 时的代码）；代码以后改了，以代码为准。

## 一句话

一个纯前端的 Three.js 小游戏：冰箱上的每块冰箱贴是一个可以旋转缩放的立方体小世界，你操控一个小人在里面走、捡 3 样东西，合成下一块冰箱贴，去下一个世界。没有框架、没有 TypeScript、没有外部美术资源——所有模型、贴图、音效都是代码现场拼出来、画出来、合成出来的。

## 几个先记住的概念

- **世界（scene / world）**：`src/scenes/` 里每个文件导出一个"世界定义"对象（`def`），`src/world.js` 的 `World` 类拿着它搭出一个 Three.js 的 `Group`。
- **冰箱贴（magnet）**：解锁了哪个世界。小屋是家，不算冰箱贴；冰箱放在小屋里。
- **物品（item）**：每个世界藏 3 样，集齐就合成下一个世界的冰箱贴。
- **修复点（repair）**：霓虹夜都是"破败世界"：到的时候停电，要把上一个世界（像素小镇）捡到的 3 样东西放回原处。
- **材料（material）**：夜都里翻垃圾桶、草丛捡瓶子，带回小屋在工作台上做壁纸和地板。
- **kit**：造型工具箱。同一套"积木"（方块、球、圆柱…）按世界风格换材质：动森风 `cozy` / 童话风 `toon` / 像素风 `pixel`。

## 运行

```bash
npm install
npm run dev
```

- 测试场景：网址加 `?test=terrain`（地形层高试验场，`&level=0.4` 可换层高）
- 宣传片模式：网址加 `?trailer`
- 调试：浏览器控制台里 `window.__mw` 能看到 `state`、当前 `world`、`camera`，还能 `__mw.travel('city')` 直接切世界、`__mw.step(60)` 手动推进 60 帧
