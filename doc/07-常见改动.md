# 07 · 常见改动该改哪儿

改之前先看一眼 `AGENTS.md` 的规矩（不写魔法数字、摆东西用 `world.heightAt`、模型构造函数是纯的、老存档要能用、每个函数写中文 JSDoc…）。

## 加一个新世界

1. 在 `src/scenes/` 新建 `xxx.js`，照 `forest.js` 抄一份：导出 `id`、`name`、`emoji`、`style`、`styleLabel`、`magnetStyle`、`bg`、`lights`、`camera`、`spawn`、`next`、`items`（3 样，每样有 `make(kit)`）、`build(w)`。
2. 在 `src/scenes/index.js` 里 import，放进 `SCENES`，插进 `ORDER`。
3. 把上一个世界的 `next` 指向它，它自己的 `next` 指向原来的下一个。
4. `style.css` 里加一个 `.magnet--你的magnetStyle` 冰箱贴样式（可以先借用已有的）。
5. 上一个世界藏的 3 样东西，最好是这个新世界的"种子"（见 04 篇第 2 节）。

世界长大了（几百行以上）就照 `scenes/city/` 拆成文件夹：`layout.js` 放地图和坐标、`models.js` 放纯模型、每个系统/剧情线一个模块，`index.js` 的 `build` 只负责把它们接起来。

## 给世界加地形（高低）

在定义里加 `terrain: { map: MAP, level: 0.5 }`，`build` 里调 `w.terrain.build(w, { grass, dirt, … })` 画占位方块。之后：

- 所有摆东西的 `y` 用 `w.heightAt(x, z)`；
- 世界大小、边界、全貌取景、阴影范围会自动跟着地图走；
- 但没接地图的老世界里写死的 10×10（地面方块、边界 ±4.55、雨和萤火虫的范围）要一起改（`TODO.md` 第 2 条有记）。

## 加一个要收集的物品

1. 在世界定义的 `items` 里加 `{ id, name, icon, hint, make(kit) }`。`hint` 是目标栏格子悬停时的提示。
2. 在 `build` 里 `w.placeItem(id, x, y, z, { spin, ry, scale, hidden })`。
3. 要等某件事发生才出现：`hidden: true`，事情发生时 `w.revealItem(id, instant)`。

注意集齐 `items.length` 样就会合成，所以一个世界的物品数就是收集目标。

## 加一个小人

```js
w.villager({
  name: '波波',
  speed: 0.85,                          // 可选
  look: { hair, shirt, pants, shoes, hat: 'gnome', hatColor, umbrella },
  lines: ['第一句', '第二句'],           // 轮流说
}, x, z);
```

- 想让它根据进度说话：`v.onTalk = () => '…'`（返回 `null` 就用 `lines`），或者进度变了以后改 `v.lines`。
- 想让它一直待在一处做一件事：`v.pin({ emote: '💤', sit: true, seatY: 0.45, face: 0 })`。
- 想让它闲逛时有地方去：`w.poi(x, z, { emote: '📖', face: Math.PI, dur: 6, sit, seatY })`。
- 第一次进世界主动打招呼：世界定义里 `greet: { name, text }`。

## 加一个能互动的东西

```js
w.interact('vending', obj, standX, standZ, {
  reach: 1.3,
  icon: '🥤',
  short: '售货机',                      // 手机互动按钮上的短字
  label: () => '投币买一罐咖啡',          // 底部提示，可以是函数
  available: () => true,                 // 返回 false 时先不出现
  fn() { … },
});
```

`obj` 被点到时会走过去；站到 `(standX, standZ)` 附近 `reach` 内按 E 触发。

## 加能翻找材料的地方

1. 世界定义里有 `materials: [{ id, name, icon, make }]` 和 `scatter: [{ material, count, from: [标签…] }]`。
2. `build` 里 `w.hideout(id, obj, x, z, { tags: ['bin'], name: '垃圾桶', icon: '🗑️', show: 'inside' })`。
3. 每次进世界会按 `scatter` 随机藏，翻过就空，下次进来重新藏。材料存进全局背包 `state.materials`。

## 加一个修复点（破败世界）

1. 世界定义里 `repairs: [{ id, from: '上一个世界', hint, msg }]`，`brokenGoal: '…'`。`id` 要和 `from` 世界里某个物品的 id 一样（目标栏用它的图标、名字）。
2. `build` 里 `w.repairSpot(id, ghostify(模型), x, y, z, { reach, seeR, can, fn(instant) { … } })`。
3. `fn` 一定要处理 `instant`（读档恢复时直接变好，不播动画）。
4. 改进度相关的东西时，想清楚老存档会走到哪条路（见 05 篇）。

## 加一种壁纸 / 地板

在 `src/decor.js` 的 `WALLPAPERS` 或 `FLOORS` 里加一条：`{ id, name, cost: { plastic: 3 }, paint(context, w, h), … }`。`paint` 画一块能无缝平铺的图案。壁纸还要 `wainscot`（墙裙色）和 `backdrop`（方块外面的 CSS 渐变）。**别删已有的 id**：老存档里可能正用着（删了会退回默认款并警告）。

## 加一个音效

`src/audio.js` 的 `sfx` 对象里加一个方法，用 `tone(频率, 开始秒, 时长, { type, vol, slide })` 拼。不需要音频文件。

## 让挡住人的大件变半透明

`w.fadeable(楼的 Group)`。只登记楼这种大件，树、路灯不用。

## 加一个"往里看"的东西

在模型上挂 `obj.userData.peek = { target: [x, y, z], from: [dx, dy, dz] }`：点它时镜头飞到 `target + from` 看 `target`。

## 改完怎么检查

```bash
npm run dev
```

- 打开浏览器看控制台有没有报错，走一走改过的地方；
- 用 `__mw.travel('city')` 直接跳到要测的世界；
- 改了存档相关的，用旧存档测一下（先备份 localStorage，见 05 篇）；
- 发布前 `npm run build` 确认能打包。
