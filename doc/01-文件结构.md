# 01 · 文件结构

```
micro_world/
├── index.html              唯一的页面：一块 <canvas> + 所有界面元素（HUD、对话框、冰箱、工作台、合成动画、结局…）
├── package.json            依赖只有 three（运行时）和 vite（开发/打包）
├── vite.config.js          Vite 配置：base './'（部署到 GitHub Pages 子路径）+ 一个开发用小接口（存宣传片视频）
├── .github/workflows/
│   └── deploy.yml          推到 main 后自动 npm ci → build → 发布到 GitHub Pages
├── README.md               给玩家/新人的介绍
├── AGENTS.md               给 AI 写代码的规矩（命名、注释、提交…），人也值得一看
├── TODO.md                 讨论过、还没做的计划和规格（地形规格、家装、材料合成、建模替换…）
├── doc/                    ← 你正在看的这组文档
├── recordings/             宣传片录出来的视频（不进 git）
├── dist/                   打包产物（不进 git）
└── src/
    ├── main.js             入口。渲染器、镜头、输入、点击判定、收集/修复/合成、冰箱、小游戏、主循环
    ├── world.js            World 类：一个世界的容器（碰撞、物品、修复点、互动、翻找、寻路、小人）
    ├── villager.js         Villager 类：小人的外形、走路动画、日常 AI、玩家操控、对话状态
    ├── terrain.js          Terrain 类：用文字地图描述的有高低的地面（高度查询、崖边判定、占位方块）
    ├── terrain-soft.js     地形的圆润外观：一整张起伏的网格、磨圆的崖边、土层、会流的水（童话森林用）
    ├── terrain-voxel.js    地形的像素外观：0.25 的小体素、弯弯的路、崖顶亮边和垂下来的草、像素波纹的水（像素小镇用）
    ├── voxel.js            体素模型：一堆小方块拼成一个网格（只画露在外面的面），颜色分暗、本色、亮三档
    ├── path-distance.js    一点离一组折线（小路）多远
    ├── kit.js              Kit 造型工具箱（按风格换材质）+ rng 可复现随机数 + 楼房立面/画布贴图工具
    ├── fx.js               特效：闪光粒子、表情气泡、光晕、霓虹字、萤火虫、星空、底部软阴影
    ├── occlusion.js        人被楼挡住时，把挡住的楼变半透明
    ├── audio.js            WebAudio 现场合成的音效和环境声（雨、城市、海浪），不用任何音频文件
    ├── ui.js               DOM 界面：标题卡、目标栏、材料栏、提示、对话、冰箱、工作台、合成动画、小游戏界面、结局
    ├── state.js            存档：读写 localStorage，进度查询的小函数，材料背包
    ├── decor.js            小屋装修目录：壁纸、地板的配方和图案（画布现画）
    ├── plants.js           植物模型：三种树、灌木、成片的花和草（InstancedMesh），风吹树冠；森林和小屋花园共用
    ├── butterflies.js      蝴蝶：绕着花丛飞，人走近会惊飞；森林、小屋花园、像素小镇共用
    ├── splashes.js         水面上的波纹和水珠（圆的或方的）；森林和像素小镇共用
    ├── tetris.js           俄罗斯方块逻辑，画到两张 canvas 上，再贴到夜都大楼正面
    ├── style.css           全部样式
    ├── scenes/             每个世界一个文件；大的世界一个文件夹
    │   ├── index.js        世界注册表：SCENES、ORDER（解锁顺序）、HOME、MAGNETS、WORLDS
    │   ├── home/           🏠 我的小屋（起点、冰箱、工作台、换壁纸地板）
    │   │   ├── index.js    世界定义 + build()
    │   │   ├── layout.js   房子多大、镜头怎么看、家具（FURNITURE、STOOLS）和花园里各样东西的位置
    │   │   ├── room.js     地板、两面墙（后墙开了窗洞）、墙上的画和会跳的钟，换壁纸地板时换贴图
    │   │   ├── window.js   窗户的模型：窗框、玻璃、窗台、窗帘
    │   │   ├── materials.js    家具共用的材质：木纹、拼布、毛线、编织地毯、藤编；圆角方块按大小分段
    │   │   ├── furniture-models.js 家具的模型（只造不摆）：床、灯、书架、厨房、冰箱、茶桌、凳子、盆栽、收音机柜……
    │   │   ├── furniture.js    把家具摆进屋里，登记碰撞和兴趣点（凳子挡人，小人一步坐上去）
    │   │   ├── workbench.js    工作台：走过去按 E 换壁纸、地板

    │   │   ├── puffs.js    软软的一小团雾：茶壶的热气
    │   │   ├── life.js     窗帘晃、茶壶冒热气、收音机飘音符
    │   │   ├── touch.js    碰一下会有反应：踢毛线球、脚步声
    │   │   ├── eaves.js    墙顶的房檐
    │   │   ├── garden.js   屋外一圈花园：篱笆院门、小路、树、花、草、蝴蝶（只是看的）
    │   │   ├── garden-ground.js    花园的地面：圆角草地、土路、侧面的土层
    │   │   ├── garden-models.js    花园里的小模型：篱笆、院门、信箱、向日葵、台阶、踏脚石
    │   │   ├── garden-path.js      小路在哪，一点离路多远
    │   │   └── people.js   居民和台词
```

## 依赖关系一览

```
index.html ──► main.js
                 ├── scenes/index.js ──► 各个世界（home / forest/ / pixel/ / city/ / london / beach / terrain-test）
                 │                         └── 用 kit.js、fx.js、audio.js、decor.js、tetris.js、world.js(ghostify)…
                 ├── world.js ──► kit.js、fx.js、villager.js、terrain.js、state.js、audio.js
                 ├── ui.js ──► state.js、decor.js、scenes/index.js、audio.js
                 ├── state.js（谁都可能用，纯数据）
                 ├── audio.js
                 ├── occlusion.js
                 └── trailer/index.js（动态 import，只在 ?trailer 时加载）
```

两个要点：

1. **`main.js` 是唯一知道"全局"的地方**：当前世界、玩家、镜头、正在聊天的人、正在玩的小游戏都是它的模块级变量。别的模块只拿到自己需要的东西（比如 `World` 构造时拿到一个 `env` 对象，里面是灯光和几个回调）。
2. **世界文件只依赖工具模块，不依赖 `main.js`**。世界要通知外面（弹提示、刷新目标栏、开工作台、开始小游戏），都通过 `world.env` 里的回调。
